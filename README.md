# PeakShield Roofing - Vanilla HTML, CSS & JavaScript Platform

A premium commercial and residential roofing platform converted into **100% pure Vanilla HTML, CSS, and JavaScript**.

No React build process, bundler, or Node.js environment is required. You can deploy it to GitHub Pages directly from the repository root (`/`) or open `index.html` straight in any browser!

---

## গিটহাব পেজেসে লাইভ করার নিয়ম (Deploy to GitHub Pages Without Build)

1. আপনার গিটহাব রিপোজিটরিতে কোড পুশ করুন (`main` ব্রাঞ্চে)।
2. রিপোজিটরির **Settings** > **Pages** ট্যাবে যান।
3. **Build and deployment** সেকশনে:
   - **Source**: `Deploy from a branch` নির্বাচন করুন।
   - **Branch**: `main` নির্বাচন করুন।
   - **Folder**: `/ (root)` সিলেক্ট করুন (যেহেতু এখন কোনো বিল্ড ছাড়াই সরাসরি `index.html` রান করবে)।
4. **Save** বাটনে ক্লিক করুন। ১ মিনিটের মধ্যে ওয়েবসাইটটি সরাসরি লাইভ হয়ে যাবে:
   `https://ghafrishamsaal-lab.github.io/Roffing-company-/`

## বৈশিষ্ট্যসমূহ (Features Included in Single-File Vanilla)

1. **কোনো বিল্ড স্টেপ নেই**: কোনো `npm run build` বা Node.js ছাড়াই ব্রাউজারে সরাসরি চলে।
2. **রিলেটিভ পাথ (`./`)**: সমস্ত ছবি, লিংক ও স্ক্রিপ্ট পাথ `./` দিয়ে শুরু করা হয়েছে।
3. **ইন্টারেক্টিভ বিফোর ও আফটার স্লাইডার**: মাউস এবং মোবাইল টাচ ড্র্যাগ সাপোর্টসহ রিয়েলটাইম স্লাইডার।
4. **ইন্টারেক্টিভ কোট ক্যালকুলেটর**: রুফ সাইজ স্লাইডার এবং সার্ভিস অনুযায়ী লাইভ প্রাইস এস্টিমেটর।
5. **প্রোজেক্ট ফিল্টার ট্যাব**: Residential, Commercial, Metal ফিল্টারিং (Vanilla JS)।
6. **এফএকিউ অ্যাকর্ডিয়ন**: স্মুথ এক্সপ্যান্ড/কোল্যাপ্স অ্যানিমেশন।
7. **সম্পূর্ণ রেসপন্সিভ**: মোবাইল, ট্যাবলেট ও ডেস্কটপের জন্য পারফেক্ট লেআউট এবং মোবাইল স্টিকি কল বাটন।
